## Implementation plan: peek extraction (including compact-terminal)

### Established baseline
`memory-api/crates/memory-api` is deleted. `peek` must use `memory_kernel = { git = "https://github.com/mankinskin/memory-kernel", branch = "main" }`; local relative paths belong only in a root `[patch]` override. Ticket `1b7e0c3d` proved the patch-free remote-kernel build.

Create public crate `peek` re-exporting internal `peek-api`, with empty defaults and feature-gated `peek` and `peek-mcp` bins built on `transport-harness` from `memory-kernel`, following the ticket-pilot consolidation in ticket `26da8f59`. Keep peek-specific typed `EntityManifest` helpers, if any, as `peek-api` extension traits preserving the same `extra` keys; do not add peek types to `memory-kernel`.

### Verified source surface
- Peek API and transports: `memory-api/crates/peek-api`, `memory-api/tools/cli/peek-cli`, `memory-api/tools/mcp/peek-mcp`.
- Companion compact-terminal surface to move in the same repository: `memory-api/crates/compact-terminal-api`, `memory-api/tools/cli/compact-terminal-cli`, `memory-api/tools/mcp/compact-terminal-mcp`.
- No `peek-http`, viewer, or non-self `peek-api` Cargo consumer exists today.

### Execution
1. Consolidate `peek-cli` and `peek-mcp` into `peek` bins first. Preserve bare `peek` and suffix `peek-mcp` names.
2. Move the compact-terminal API and transports with the peek repository as a companion package; retain existing compact-terminal public command contracts rather than renaming them to `peek`.
3. Move `peek-api`, `peek`, and compact-terminal packages to the new repository; repoint the root workspace membership and any future consumers to git dependencies.
4. Keep all domain manifest accessors out of `memory-kernel` and preserve store bytes.

### Acceptance criteria
```bash
cargo test -p peek-api -p peek-cli -p peek-mcp -p compact-terminal-api -p compact-terminal-cli -p compact-terminal-mcp
cargo build --manifest-path "$TOOL_REPO/Cargo.toml" --no-default-features
cargo test --manifest-path "$TOOL_REPO/Cargo.toml" --all-features
cargo test --workspace
```

### Risk
The standalone repository cannot be proven until `memory-kernel` is published and its git URL resolves from a patch-free checkout. Compact-terminal package boundaries must be preserved during the shared-repository move.
