## Objective

Add the `http` feature and `pdf-http` binary to the `pdf` facade crate,
completing the three-transport set the domain crate contract defines.

## Files

- `memory-api/crates/pdf/Cargo.toml` — add the `http` feature and `[[bin]]`
- `memory-api/crates/pdf/src/bin/pdf-http.rs` (new)
- `memory-api/crates/pdf/src/http.rs` (new, feature-gated)

## Design

Per `WORKFLOW_TOOLS_DOMAIN_CRATE_CONTRACT.md`:

```toml
http = ["dep:transport-harness", "transport-harness/http"]

[[bin]]
name = "pdf-http"
path = "src/bin/pdf-http.rs"
required-features = ["http"]
```

`memory-api/crates/ticket/Cargo.toml` and its `ticket-http` bin are the in-repo
reference.

## Considerations Before Starting

Do not start this without answering these — an HTTP surface for a
file-writing tool is a materially larger security surface than stdio MCP:

- **Who can reach it?** Localhost-only by default, or bindable? A network-
  reachable PDF-writing endpoint is a remote file-write primitive.
- **Authentication.** Does the harness provide it, or does this need its own?
- **Sandbox root.** Same problem as T7 but worse: the root must be
  server-configured and never caller-widenable.
- **Upload handling.** Does the API accept PDF bytes over the wire, or only
  server-local paths? Accepting bytes means body size limits, temp file
  lifecycle, and cleanup.
- **Resource limits.** Concurrent request caps and per-request timeouts,
  especially for the typst path from T5 which spawns an external process.

## Acceptance Criteria

- [ ] `cargo build -p pdf --features http` produces `pdf-http`.
- [ ] `cargo build -p pdf --features cli,mcp,http` builds all three.
- [ ] Every `pdf-api` operation has an endpoint.
- [ ] Errors map to sensible HTTP status codes via `PdfError::is_user_error()`.
- [ ] Sandbox root is server-configured and not caller-widenable.
- [ ] The binding/auth decision is recorded and implemented.
- [ ] Resource limits are in place for the typst path.

## Depends On

The v1 track (T7 at minimum) must be complete first, so the API surface is
stable before a third transport binds to it.
