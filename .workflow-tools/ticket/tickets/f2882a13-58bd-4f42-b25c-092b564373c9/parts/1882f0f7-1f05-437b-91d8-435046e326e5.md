## Implementation plan: interview repository skeleton

### Established baseline
`memory-api/crates/memory-api` is deleted. The placeholder must depend on `memory_kernel` from `https://github.com/mankinskin/memory-kernel` branch `main`; relative local paths belong only in a root `[patch]` override. Ticket `1b7e0c3d` proved patch-free remote-kernel resolution.

Create public crate `interview` re-exporting internal `interview-api`, with no default features and feature-gated `interview`, `interview-mcp`, and `interview-http` bins on `transport-harness` from `memory-kernel`. The binary names follow the ticket pilot shape in ticket `26da8f59`. Any future interview-specific typed manifest accessors belong in `interview-api` extension traits preserving the same `extra` keys, never in `memory-kernel`.

### Verified source surface
- `memory-api/crates/interview-api` is absent.
- No `memory-api/tools/{cli,mcp,http}/interview-*` crate exists.
- No interview viewer exists.
- No other Cargo manifest currently consumes `interview-api`.

### Execution
1. Create the standalone interview repository skeleton only: workspace manifest, public `interview` crate, internal `interview-api`, empty default features, and compiling feature-gated binary stubs.
2. Do not claim migration parity or invent persistence/schema behavior while no in-tree interview implementation exists.
3. Commit the remote `memory-kernel` dependency and allow a relative development override only at the repository root.
4. Document the skeleton as the future destination for the currently linked interview workflow, not as an extraction of nonexistent legacy code.

### Acceptance criteria
```bash
cargo build --manifest-path "$TOOL_REPO/Cargo.toml" --no-default-features
cargo test --manifest-path "$TOOL_REPO/Cargo.toml" --all-features
cargo tree --manifest-path "$TOOL_REPO/Cargo.toml" -i memory-kernel
```

### Risk
The skeleton cannot prove an interview product contract because no legacy interview API or transport exists. It still requires published `memory-kernel` for a patch-free standalone build.
